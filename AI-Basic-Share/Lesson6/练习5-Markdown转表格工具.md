# 练习 5：Markdown 转表格工具

---

## 练习目标

编写一份小工具需求说明，让 AI 生成一个 Markdown 转表格工具，将 Markdown 格式的测试用例或文档转换为 CSV 或 Excel 格式。

---

## 练习步骤

1. 阅读下方的需求模板和样例 Markdown
2. 填写需求说明中的目标、输入、输出、规则
3. 将需求说明提交给 Copilot 或公司内网模型
4. 运行生成的工具，用样例 Markdown 验证
5. 根据验证结果迭代修正

## 样例 Markdown

将以下内容保存为 `test_cases.md` 用于验证：

```markdown
# 登录功能测试用例

## 正常场景

### TC-001 正确账号密码登录
- 前置条件：用户已注册，账号状态正常
- 操作步骤：
  1. 打开登录页面
  2. 输入正确用户名
  3. 输入正确密码
  4. 点击登录按钮
- 期望结果：登录成功，跳转到首页

### TC-002 记住我功能
- 前置条件：用户已注册
- 操作步骤：
  1. 勾选"记住我"
  2. 输入正确账号密码
  3. 点击登录
  4. 关闭浏览器重新打开
- 期望结果：无需重新登录

## 异常场景

### TC-003 密码错误
- 前置条件：用户已注册
- 操作步骤：
  1. 输入正确用户名
  2. 输入错误密码
  3. 点击登录
- 期望结果：提示"密码错误"，停留在登录页

### TC-004 账号已锁定
- 前置条件：账号已被锁定
- 操作步骤：
  1. 输入正确账号密码
  2. 点击登录
- 期望结果：提示"账号已被锁定，请 30 分钟后再试"
```
