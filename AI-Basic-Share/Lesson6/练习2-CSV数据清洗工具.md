# 练习 2：CSV 数据清洗工具

---

## 练习目标

编写一份小工具需求说明，让 AI 生成一个 CSV 数据清洗脚本，并验证其可用性。

---

## 练习步骤

1. 阅读下方的需求模板和样例数据
2. 填写需求说明中的目标、输入、输出、规则
3. 将需求说明提交给 Copilot 或公司内网模型
4. 运行生成的脚本，用样例数据验证
5. 根据运行结果迭代修正

## 常见清洗规则参考

| 规则 | 说明 |
|------|------|
| 去重 | 删除重复的 user_id |
| 空值检查 | 检查 name、email 为空的行 |
| 邮箱格式 | 检查 email 是否符合标准格式 |
| 年龄范围 | age 是否在 0~120 之间 |
| 状态值 | status 是否在允许的列表中 |
| 日期格式 | created_at 是否为有效日期 |
