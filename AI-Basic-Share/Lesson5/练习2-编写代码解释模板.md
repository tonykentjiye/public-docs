# 练习 2：编写代码解释 Markdown 模板

---

## 练习目标

编写一份可复用的代码解释 Markdown 模板，让团队成员能用统一格式让 AI 解释陌生代码。

---

## 练习步骤

1. 阅读下方的参考模板
2. 根据你自己的工作经验，修改或补充模板内容
3. 将模板保存为 `.md` 文件
4. 用 Copilot 验证一次（选中一段代码后使用模板）
5. 根据验证结果调整模板

---

## 参考模板

```markdown
# 代码解释

## 背景

[描述这段代码所属的模块、业务场景]

## 代码

```python
# 粘贴需要解释的代码
```

## 希望输出

1. 一句话总结这段代码的功能
2. 输入参数说明（类型、含义、可选值）
3. 核心处理流程（分步骤说明）
4. 返回值说明
5. 可能异常和边界条件
6. 需要人工确认的问题

## 注意事项

- 用简洁的语言解释，避免过度展开
- 如果代码中有不常见的模式或写法，请特别说明
- 指出代码中可能存在的风险或改进空间
```
