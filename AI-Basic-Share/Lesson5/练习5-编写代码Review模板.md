# 练习 5：编写代码 Review Markdown 模板

---

## 练习目标

编写一份可复用的代码 Review Markdown 模板，让团队成员能用统一格式让 AI 辅助代码审查。

---

## 练习步骤

1. 阅读下方的参考模板
2. 根据你自己的工作经验，修改或补充模板内容
3. 将模板保存为 `.md` 文件
4. 用 Copilot 验证一次（选中一段代码后使用模板）
5. 根据验证结果调整模板

---

## 参考模板

```markdown
# 代码 Review

## 背景

[描述本次 Review 的模块、变更目的、关联需求或 Issue]

## 变更文件

- [文件路径 1]
- [文件路径 2]

## 代码

```python
# 粘贴需要 Review 的代码
```

## 希望输出

请从以下角度审查代码，按严重程度排序：

### 1. 正确性
- 逻辑是否有明显错误？
- 边界条件是否处理？

### 2. 异常处理
- 是否有未捕获的异常？
- 错误信息是否清晰？

### 3. 可读性
- 命名是否清晰？
- 是否有过长方法或复杂分支？

### 4. 测试覆盖
- 哪些场景缺少测试？
- 现有测试是否充分？

## 注意事项

- 按严重程度排序（高/中/低）
- 每个问题说明为什么需要关注
- 只指出问题，不直接改写代码
- 如果信息不足，请指出需要补充什么
```
