# 练习 1：编写 Bug 分析 Markdown 模板

---

## 练习目标

编写一份可复用的 Bug 分析 Markdown 模板，让团队成员能用统一格式向 AI 提交 Bug 分析请求。

---

## 练习步骤

1. 阅读下方的参考模板
2. 根据你自己的工作经验，修改或补充模板内容
3. 将模板保存为 `.md` 文件
4. 用 Copilot 或公司内网模型验证一次
5. 根据验证结果调整模板

---

## 参考模板

```markdown
# Bug 分析

## 背景

[描述 Bug 所属的功能模块、环境、影响范围]

## 现象

[描述 Bug 的外部表现，用户看到了什么]

## 复现步骤

1. [步骤 1]
2. [步骤 2]
3. [步骤 3]

## 期望结果

[描述正常情况下应该是什么结果]

## 实际结果

[描述实际发生了什么]

## 相关代码

```python
# 粘贴相关代码片段
```

## 错误日志

```
粘贴错误日志或异常堆栈
```

## 希望输出

- 可能原因（按概率排序）
- 每个原因的验证方法
- 建议修改方向
- 还需要补充哪些信息

## 注意事项

- 只分析原因，不要直接修改代码
- 如果信息不足，请指出需要补充什么
```
