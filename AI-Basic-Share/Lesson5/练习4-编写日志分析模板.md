# 练习 4：编写日志分析 Markdown 模板

---

## 练习目标

编写一份可复用的日志分析 Markdown 模板，让团队成员能用统一格式让 AI 分析异常日志。

---

## 练习步骤

1. 阅读下方的参考模板
2. 根据你自己的工作经验，修改或补充模板内容
3. 将模板保存为 `.md` 文件
4. 用公司内网模型或 Copilot 验证一次
5. 根据验证结果调整模板

---

## 参考模板

```markdown
# 日志分析

## 背景

[描述服务名、接口名、环境、发生时间]

## 异常日志

```
粘贴完整异常日志，包含时间戳和堆栈
```

## 相关配置

[如有，粘贴相关配置信息]

## 最近变更

[如有，描述最近代码或配置变更]

## 希望输出

1. 错误摘要（一句话总结）
2. 关键异常位置（哪个类、哪行代码）
3. 可能原因排序（按概率从高到低）
4. 建议检查项
5. 需要补充的日志或配置信息

## 注意事项

- 区分直接原因和根因
- 如果信息不足，请指出需要补充什么
- 给出排查步骤，而不是直接给结论
```
