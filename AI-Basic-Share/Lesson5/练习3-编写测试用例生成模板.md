# 练习 3：编写测试用例生成 Markdown 模板

---

## 练习目标

编写一份可复用的测试用例生成 Markdown 模板，让团队成员能用统一格式让 AI 根据需求生成测试点。

---

## 练习步骤

1. 阅读下方的参考模板
2. 根据你自己的工作经验，修改或补充模板内容
3. 将模板保存为 `.md` 文件
4. 用公司内网模型或 Copilot 验证一次
5. 根据验证结果调整模板

---

## 参考模板

```markdown
# 测试用例生成

## 背景

[描述功能模块、项目阶段、测试类型]

## 功能说明

[一句话描述要测试的功能]

## 输入字段

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| | | | |
| | | | |

## 业务规则

- [规则 1]
- [规则 2]
- [规则 3]

## 异常处理

- [异常情况 1 的处理方式]
- [异常情况 2 的处理方式]

## 权限要求

[说明哪些角色可以访问、哪些不能]

## 希望输出

请按以下分类输出测试点：

### 正常场景
- 每条包含：用例名称、前置条件、操作步骤、期望结果

### 异常场景
- 每条包含：用例名称、异常条件、期望结果

### 边界场景
- 每条包含：用例名称、边界值、期望结果

### 权限场景（如有）
- 每条包含：用例名称、角色、期望结果

## 注意事项

- 优先覆盖核心业务流程
- 异常场景至少包含输入校验和业务规则违反
- 边界场景关注字段长度、数值范围、时间临界点
```
