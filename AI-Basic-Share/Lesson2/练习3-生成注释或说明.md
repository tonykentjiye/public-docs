# 练习 3：让 Copilot 生成注释或说明

---

## 练习目标

使用 Copilot 为一段没有注释的代码生成注释和方法说明，学习如何让 AI 辅助文档编写。

---

## 练习步骤

1. 将下方示例代码保存为 `example_score_analyzer.py`
2. 在 VS Code 中打开该文件
3. 选中全部代码
4. 在 Copilot Chat 中输入：
   > "请为这段代码生成方法说明注释，包含功能描述、参数说明、返回值说明和异常情况"
5. 阅读 Copilot 生成的注释
6. 判断注释是否准确、简洁、有用
7. 手动修正不准确或多余的部分

## 示例代码（无注释版）

```python
# example_score_analyzer.py
# 注意：这段代码没有任何注释，请让 Copilot 帮你生成


def analyze(scores, mode="standard"):
    if not scores:
        return {"error": "数据为空"}

    if not isinstance(scores, list):
        return {"error": "输入必须是列表"}

    if len(scores) < 2:
        return {"error": "数据量不足，至少需要 2 个分数"}

    for s in scores:
        if not isinstance(s, (int, float)):
            return {"error": f"分数必须为数字，发现非法值: {s}"}

    total = sum(scores)
    count = len(scores)
    avg = round(total / count, 2)
    maximum = max(scores)
    minimum = min(scores)

    sorted_scores = sorted(scores)
    if count % 2 == 1:
        median = sorted_scores[count // 2]
    else:
        mid = count // 2
        median = round((sorted_scores[mid - 1] + sorted_scores[mid]) / 2, 2)

    variance = sum((x - avg) ** 2 for x in scores) / count
    std_dev = round(variance**0.5, 2)

    result = {
        "count": count,
        "total": total,
        "average": avg,
        "median": median,
        "max": maximum,
        "min": minimum,
        "std_dev": std_dev,
    }

    if mode == "simple":
        return {"count": count, "average": avg, "max": maximum, "min": minimum}

    if mode == "pass_fail":
        passed = sum(1 for s in scores if s >= 60)
        failed = count - passed
        result["passed"] = passed
        result["failed"] = failed
        result["pass_rate"] = round(passed / count * 100, 1)

    return result
```
