# 练习 2：让 Copilot 列出边界条件

---

## 练习目标

使用 Copilot 分析一段代码的边界条件和潜在异常情况，培养"写完代码先想边界"的习惯。

---

## 练习步骤

1. 将下方示例代码保存为 `example_password_checker.py`
2. 在 VS Code 中打开该文件
3. 选中全部代码
4. 在 Copilot Chat 中输入：
   > "请分析这段代码的边界条件和潜在异常情况，列出所有可能的输入组合和对应的输出"
5. 阅读 Copilot 的分析
6. 对照代码验证分析是否全面

---

## 示例代码

```python
# example_password_checker.py
import re


def check_password_strength(password: str) -> dict:
    """
    检查密码强度，返回评分和反馈信息。

    评分规则：
    - 长度 >= 8 得 1 分
    - 包含大写字母得 1 分
    - 包含小写字母得 1 分
    - 包含数字得 1 分
    - 包含特殊字符得 1 分
    - 满分 5 分
    """
    result = {"score": 0, "strength": "", "feedback": []}

    if len(password) >= 8:
        result["score"] += 1
    else:
        result["feedback"].append("密码长度至少 8 位")

    if re.search(r"[A-Z]", password):
        result["score"] += 1
    else:
        result["feedback"].append("需要包含大写字母")

    if re.search(r"[a-z]", password):
        result["score"] += 1
    else:
        result["feedback"].append("需要包含小写字母")

    if re.search(r"[0-9]", password):
        result["score"] += 1
    else:
        result["feedback"].append("需要包含数字")

    if re.search(r"[!@#$%^&*(),.?\":{}|<>]", password):
        result["score"] += 1
    else:
        result["feedback"].append("需要包含特殊字符")

    if result["score"] <= 2:
        result["strength"] = "弱"
    elif result["score"] <= 4:
        result["strength"] = "中"
    else:
        result["strength"] = "强"

    return result
```
