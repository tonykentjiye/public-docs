# 练习 4：测试用例补充

---

## 练习目标

使用 Copilot 根据需求描述生成测试点清单，练习从需求中拆解测试场景的能力。

---

## 练习步骤

1. 将下方需求描述复制到 Copilot Chat 中
2. 使用测试用例 Prompt 模板提问
3. 阅读 Copilot 生成的测试点
4. 检查是否有遗漏或错误的测试点
5. 补充你认为需要但 AI 没有列出的测试点

---

## 测试用例 Prompt 模板

```
请根据以下需求生成测试点：

- 功能说明：用户注册功能
- 输入字段：用户名、邮箱、密码、确认密码
- 业务规则：
  1. 用户名 3~20 个字符，只能包含字母、数字和下划线
  2. 邮箱必须符合标准邮箱格式
  3. 密码至少 8 位，必须包含大写字母、小写字母和数字
  4. 确认密码必须与密码一致
  5. 用户名和邮箱不能重复（需要调用后端校验接口）
  6. 注册成功后发送验证邮件
- 异常处理：各字段校验失败时返回具体错误提示
- 权限要求：无需登录

请按正常场景、异常场景、边界场景、安全场景输出。
```

## 参考：测试点分类示例

| 分类 | 示例 |
|------|------|
| **正常场景** | 输入合法信息注册成功、注册后收到验证邮件 |
| **异常场景** | 用户名已存在、邮箱已注册、密码与确认密码不一致 |
| **边界场景** | 用户名 3 个字符 / 20 个字符、密码 8 位 / 密码 50 位 |
| **安全场景** | SQL 注入尝试、XSS 脚本注入、密码明文传输检查 |
