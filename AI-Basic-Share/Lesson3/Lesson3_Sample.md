## 1. Bug 分析模板

### 适用场景
代码运行无报错但结果不正确，需要 AI 辅助定位逻辑问题。

### 选中代码
`Online_Show.py` → `calculate_discount_v2` 和 `batch_calculate_discount` 函数

### 示例 Prompt

```
请根据以下信息分析 Bug 可能原因：

- 现象：调用 batch_calculate_discount 时，部分订单的折扣金额计算结果不正确，有时多扣有时少扣
- 复现步骤：创建包含多个商品的订单，每个商品有不同的折扣率，调用折扣计算接口
- 期望结果：每个商品按各自折扣率计算折扣金额，合计正确
- 实际结果：部分订单折扣金额与预期不符
- 相关代码：见 Online_Show.py 中 calculate_discount_v2 和 batch_calculate_discount
- 错误日志：无报错日志，计算结果不正确

请输出：可能原因、验证方法、建议修改点、还需要补充的信息。
```

### 通用模板（可替换为自己的代码）

```
请根据以下信息分析 Bug 可能原因：

- 现象：<描述错误现象>
- 复现步骤：<如何复现>
- 期望结果：<应该是什么>
- 实际结果：<实际是什么>
- 相关代码：<代码位置或片段>
- 错误日志：<如有>

请输出：可能原因、验证方法、建议修改点、还需要补充的信息。
```

## 3. 单元测试生成模板

### 适用场景
需要为某个方法生成 pytest 单元测试，覆盖正常、异常、边界场景。

### 选中代码
`Online_Show.py` → `OrderUtils.mask_phone` 方法

### 示例 Prompt

```
请为选中的 mask_phone 方法生成 pytest 单元测试，覆盖以下场景：

- 正常输入（11 位手机号）
- 空字符串
- 不足 11 位
- 超过 11 位
- 包含非数字字符
- 带空格或特殊符号

测试文件命名为 test_online_show.py，使用 pytest 框架。
```

### 通用模板（可替换为自己的方法）

```
请为选中的 <方法名> 方法生成 pytest 单元测试，覆盖以下场景：

- 正常输入
- <异常场景1>
- <异常场景2>
- <边界场景1>
- <边界场景2>

测试文件命名为 <文件名>，使用 pytest 框架。
```

### 其他可尝试的方法

| 方法 | 测试重点 |
|------|----------|
| `OrderUtils.format_order_id` | 空字符串、前后空格、大小写转换、特殊字符 |
| `OrderUtils.parse_order_date` | 多种日期格式、无效日期、None 输入 |
| `OrderUtils.validate_order_status` | 合法状态、大小写不敏感、非法状态、空字符串 |

## 4. 测试用例补充模板

### 适用场景
根据需求描述生成测试点清单，适合测试人员或开发自测时使用。

### 参考代码
`Online_Show.py` → `calculate_coupon_discount` 函数

### 示例 Prompt

```
请根据以下需求生成测试点：

- 功能说明：优惠券折扣计算
- 输入字段：订单金额(subtotal)、优惠券类型(coupon_type)、优惠值(coupon_value)、用户等级(user_level)
- 业务规则：
  1. fixed：固定金额减免，减免金额不能超过订单金额
  2. percent：百分比折扣，折扣率不能超过 50%
  3. threshold：满减，最低消费 100 元
  4. VIP 用户在计算结果上额外打 9 折
  5. 所有金额保留两位小数
- 异常处理：无效优惠券类型、负数金额、超出范围
- 权限要求：无

请按正常场景、异常场景、边界场景输出。
```

### 通用模板（可替换为自己的需求）

```
请根据以下需求生成测试点：

- 功能说明：<功能名称>
- 输入字段：<字段列表>
- 业务规则：
  1. <规则1>
  2. <规则2>
  3. <规则3>
- 异常处理：<异常情况>
- 权限要求：<如有>

请按正常场景、异常场景、边界场景、安全场景输出。
```

- 主要问题

- 边界条件
- 异常处理
- 可读性
- 测试覆盖
