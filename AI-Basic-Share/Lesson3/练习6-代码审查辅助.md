# 练习 6：代码审查辅助

---

## 练习目标

使用 Copilot 对一段代码进行审查，练习让 AI 辅助发现潜在问题，并按严重程度排序。

---

## 练习步骤

1. 将下方示例代码保存为 `example_user_api.py`
2. 在 VS Code 中打开该文件
3. 选中全部代码
4. 在 Copilot Chat 中使用代码审查 Prompt 模板提问
5. 阅读 Copilot 的审查结果
6. 判断哪些问题需要优先修复

## 示例代码（含多个问题）

```python
# example_user_api.py
import json
from flask import Flask, request, jsonify

app = Flask(__name__)


# 问题1：全局变量存储数据，不是线程安全的
users_db = {}
next_id = 1


@app.route("/api/users", methods=["POST"])
def create_user():
    global next_id
    data = request.get_json()

    # 问题2：没有检查 data 是否为 None
    username = data.get("username")
    email = data.get("email")
    age = data.get("age")

    # 问题3：用户名校验过于简单
    if not username:
        return jsonify({"error": "用户名不能为空"}), 400

    # 问题4：邮箱没有校验格式
    if not email:
        return jsonify({"error": "邮箱不能为空"}), 400

    # 问题5：age 可能不是数字，直接比较会出问题
    if age < 0 or age > 150:
        return jsonify({"error": "年龄必须在 0~150 之间"}), 400

    # 问题6：没有检查用户名是否重复
    user = {
        "id": next_id,
        "username": username,
        "email": email,
        "age": age,
    }
    users_db[next_id] = user
    next_id += 1

    return jsonify(user), 201


@app.route("/api/users/<int:user_id>", methods=["GET"])
def get_user(user_id):
    # 问题7：没有处理 user_id 不存在的情况
    user = users_db[user_id]
    return jsonify(user)


@app.route("/api/users/<int:user_id>", methods=["DELETE"])
def delete_user(user_id):
    # 问题8：删除不存在的用户会抛 KeyError
    del users_db[user_id]
    return jsonify({"message": "删除成功"})


@app.route("/api/users", methods=["GET"])
def list_users():
    # 问题9：没有分页，数据量大时会有性能问题
    return jsonify(list(users_db.values()))


if __name__ == "__main__":
    app.run(debug=True)
    # 问题10：debug=True 不能用于生产环境
```
