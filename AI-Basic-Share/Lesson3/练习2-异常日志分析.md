# 练习 2：异常日志分析

---

## 练习目标

使用 Copilot 分析一段异常日志，练习区分直接原因和根因，并给出排查步骤。

---

## 练习步骤

1. 将下方异常日志复制到 Copilot Chat 中
2. 使用日志分析 Prompt 提问
3. 阅读 Copilot 的分析结果
4. 判断分析是否合理

---

## 日志分析 Prompt 模板

```
请分析以下异常日志，按以下格式输出：

- 错误摘要
- 关键异常位置
- 可能原因排序（按概率从高到低）
- 建议检查项
- 需要补充的日志或配置

日志内容：
[粘贴日志]
```
