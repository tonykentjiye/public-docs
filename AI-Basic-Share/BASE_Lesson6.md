## 什么任务适合做成小工具

- 每周或每天重复做
- 操作步骤固定
- 输入输出格式相对稳定
- 人工处理容易出错
- 自动化后能明显节省时间

**案例或场景**

每天从日志中筛选某类错误，再统计出现次数和影响接口。这个任务非常适合做成脚本。

---

## 不适合一开始做工具的任务

- 规则还没想清楚
- 输入格式经常变化
- 判断依赖大量人工经验
- 一次性任务
- 失败成本很高且难验证

---

## AI 辅助制作小工具手顺

1. 描述问题和目标
2. 明确输入和输出
3. 给出样例数据
4. 让 AI 生成最小可用版本
5. 本地运行并记录错误
6. 把错误反馈给 AI 迭代
7. 增加异常处理和使用说明

## 场景一：日志分析脚本

**目标**

读取日志文件，统计 ERROR 类型、出现次数、最早时间和最晚时间。

**输入**

应用日志文本文件。

**输出**

Markdown 表格或 CSV 文件。

---

## 日志分析 Prompt 示例

请用 Python 生成一个日志分析脚本。

要求：

- 输入参数是日志文件路径
- 只统计包含 ERROR 的行
- 按异常类型分组统计次数
- 输出 Markdown 表格
- 增加文件不存在时的错误提示
- 给出运行命令示例

---

## 日志工具迭代方向

- 增加时间范围筛选
- 增加接口路径统计
- 输出 CSV
- 支持多个日志文件
- 按出现次数排序
- 增加 README 使用说明

## 场景二：Excel/CSV 处理

**目标**

读取 CSV 文件，按规则清洗数据并生成统计结果。

**常见任务**

- 去重
- 字段格式转换
- 按状态分组统计
- 找出缺失值
- 合并多个文件

---

## CSV 处理 Prompt 示例

请生成一个 Python 脚本处理 CSV 文件。

要求：

- 输入文件包含 user_id、status、created_at 三列
- 统计每种 status 的数量
- 检查 user_id 为空的行数
- 输出一个新的 summary.csv
- 代码中加入必要注释
- 给出 5 行样例输入和期望输出

## 场景三：测试数据生成

**目标**

根据接口字段和业务规则生成测试数据。

**适用内容**

- 正常数据
- 边界数据
- 异常数据
- 批量数据
- 随机但可复现的数据

---

## 测试数据 Prompt 示例

请根据以下规则生成测试数据脚本：

- 字段：user_id、age、email、status
- age 范围是 0 到 120
- status 只能是 active、inactive、locked
- 生成正常、边界、非法三类数据
- 输出 CSV
- 每类至少 10 条

## 场景四：内部工具雏形

**目标**

用 Copilot 辅助开发一个简单内部页面或命令行工具。

**适合例子**

- JSON 格式化和字段提取
- SQL 模板生成器
- 日志关键字查询页面
- 测试用例 Markdown 转 CSV

---

## 内部工具开发 Prompt 示例

请帮我设计一个命令行工具。

功能：

- 输入一个 Markdown 测试用例文件
- 解析用例名称、步骤、期望结果
- 输出 CSV 文件

请先给出实现思路、文件结构和关键函数，不要直接生成完整代码。

---

## 使用 Copilot 的迭代方式

- 先写 README 或需求说明
- 让 Copilot 生成文件结构
- 一个函数一个函数生成
- 每个函数配一个样例测试
- 运行失败后把报错反馈给 Copilot
- 最后补使用说明

---

## 小工具验收清单

- 能在本地按说明运行
- 有样例输入和样例输出
- 常见错误有提示
- 输出结果能人工检查
- 有最小使用说明
- 没有过度设计
